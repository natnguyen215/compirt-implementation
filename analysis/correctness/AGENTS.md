# Correctness-study guidance

Read the root `AGENTS.md` and this directory's `README.md` for the shared fold
protocol, dependency order, and package-to-results map.

- The main target is correctness conditional on observed first-buzzer identity
  and position. Keep this distinct from full timing/identity/event prediction;
  the timing study and archived frozen-skills family provide separate replay paths.
- `paper_readiness/first_buzz_features.py` supplies the reference root, shared
  features, row loading, and metrics to all three packages and `archive/frozen_skills/`.
  Changes there affect every matched comparison.
- Feature fitting, hyperparameter selection, and thresholds use training games
  only. Preserve exact inner splits, fold hashes, and held-out row alignment.
  Repeatedly reused whole-game folds are development comparisons.
- Point-fit artifacts in `tossup_accuracy_study/` precede the Bayesian study,
  which verifies the same inner split hashes. See `README.md` for run order.
- Keep the old `analysis.tossup_accuracy_study` import alias needed by saved
  joblib predictors, plus the verifier's historical dependency-path mapping.
  Moving source must not silently break saved-artifact replay.
- Write study outputs under `results/compirt/holdout/common/`, using each
  package's documented result directory. Descriptive EDA elsewhere in
  `analysis/` has a different output convention.
- `docs/correctness-benchmarks.md` is generated by
  `tossup_accuracy_study/report.py`; change the generator instead of editing
  its output. Preserve the distinction between old fitted reference artifacts
  and current normalized full-grid replay.

Tests mix pytest functions and unittest classes:

```bash
.venv/bin/python -B -m pytest -q analysis/correctness
```

Use synthetic and closed-form checks without datasets, experiment fitting, or
writes under `results/`. The aggregate repository checker includes this suite.
