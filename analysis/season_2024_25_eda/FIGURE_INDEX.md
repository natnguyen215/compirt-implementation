# Figure index

All 29 figures are regenerated by [analyze.py](analyze.py) into [figures/](figures/). Colour encodes tier throughout — Fall gold, Winter purple, Regionals blue, Nationals green — and tier is also the chronological axis, so anything reading left-to-right reads forward in time. There is no year encoding: within one season, year is collinear with tier.

There is deliberately **no event-grain MDS** here. The season has only four question-set events, and a two-dimensional embedding of four points is near-exact by construction, so it would carry no information.
