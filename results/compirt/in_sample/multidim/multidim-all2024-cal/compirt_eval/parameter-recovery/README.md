# Minimal parameter recovery

This seeded check generates a small two-dimensional sigmoid competing-risks dataset, refits it with the repository's AutoNormal SVI baseline, and resolves only dimension-label switching before scoring. The reported errors, interval coverage, and interval width are descriptive and have no built-in pass/fail cutoffs. This is a smoke test for recovery, not evidence for synergy identifiability or a replacement for a multi-size study.
